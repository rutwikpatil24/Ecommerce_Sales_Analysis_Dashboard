# Ecommerce_Sales_Analysis_Dashboard
# 🛒 E-Commerce Sales Analysis

An end-to-end **Data Analytics project** using Python, MySQL, SQL and Power BI to transform unclean Excel data into meaningful business insights.

## 📊 Dashboard Preview

![E-Commerce Sales Dashboard](images/powerbi-dashboard.png)

> **Power BI Dashboard:** Sales, Profit, Products, Cities, Payment Methods and Order Status.

## 🔄 Project Workflow

**Excel → Python/Pandas → Data Cleaning → MySQL → SQL Analysis → Power BI Dashboard**

### 🧹 Data Cleaning — Python

* Cleaned missing and invalid values
* Removed duplicate records
* Standardized text and dates
* Converted numeric columns
* Created Sales, Net Amount and Profit features
* Exported cleaned data to CSV

### 🗄️ SQL Analysis — MySQL

* Sales and order analysis
* Top products
* City-wise sales
* Monthly sales trends
* Product profitability
* Payment method analysis
* Cancelled order analysis

### 📈 Power BI Dashboard

Created an interactive dashboard to monitor:

* Total Sales
* Profit
* Orders
* Product Performance
* City Performance
* Monthly Trends
* Payment Methods
* Order Status

## 💡 Key Insights

* **380 orders** analyzed
* Approximately **₹35.15 lakh net sales**
* **Laptop** generated the highest product sales
* **Pune** recorded the highest city-level sales
* **May** had the highest sales among months with available order dates
* **Wallet** was the most-used payment method
* **94 cancelled orders** were identified

> *Profit is calculated using an assumed 20% margin for analytical purposes.*
